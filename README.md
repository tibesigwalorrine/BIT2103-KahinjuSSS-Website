
# # Kahinju Senior Secondary School Website (Fort Portal)

Dynamic website for Kahinju Senior Secondary School (BIT 2103 Practical Exam).

- **Live URL:** https://noscamcoin.org
- **Theme:** `kahinju-school` (Custom WordPress theme)
- **Plugin:** `kahinju-core` (Custom MySQL CRUD module with prepared statements & JOIN)

## Database & Local Setup
1. Import `kahinju_school.sql` into MySQL/phpMyAdmin.
2. Place `kahinju-school` in `wp-content/themes/` and `kahinju-core` in `wp-content/plugins/`.
3. Activate both inside the WordPress dashboard.
